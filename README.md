# 🎬 Movie Recommender System

A simple AI-powered Movie Recommender System that suggests similar movies based on the movie selected by the user. It uses **TF-IDF Vectorization** and **Cosine Similarity** to generate recommendations and integrates the **TMDB API** to display movie posters, ratings, overviews, and release dates.

## ✨ Features

* Search movies by title
* Get similar movie recommendations
* View movie posters, ratings, and overviews
* Fast and responsive user interface
* Real-time movie details using TMDB API

## ⚙️ Working Pipeline

Movie Title → FastAPI Backend → TF-IDF & Cosine Similarity → TMDB API → Recommended Movies
